Privacy Policy

Behind the Brand Publisher · Last updated 13 October 2026

Who uses this tool

Behind the Brand Publisher is a private tool used only by the owner of the YouTube channel "Behind the Brand | ورا البراند" (@WaraElBrand) to manage that channel. It is not offered to the public and has no other users.

What data it accesses

Using YouTube API Services and the owner's own Google sign-in (OAuth), the tool uploads and updates the owner's own videos, captions, thumbnails and playlists, reads public comments on the owner's own videos to reply to them, and reads the channel's own aggregate analytics to prepare performance reports for the owner.

What it stores

Video IDs, titles, schedules and aggregate analytics numbers for the owner's channel are stored in the owner's private code repository. Comment text is processed only to draft replies and is not kept for more than 30 days. No personal data from viewers is sold, shared or used for advertising.

Google and YouTube

This tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.

Deletion

The owner can delete all stored data by deleting the repository and revoking access. Questions: youssefatef88@gmail.com
